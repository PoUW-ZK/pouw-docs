# PoUW-ZK

Dokumentácia tímového projektu **Proof-of-Useful-Work L1 Blockchain via Proving System Outsourcing**
(FIIT STU, tím 27, 2026/2027).

Staviame L1 blockchain, v ktorom ťažiari namiesto zbytočných hashov generujú
zero-knowledge dôkazy pre klientov. Projekt vychádza z článku
[SNARKChain](https://arxiv.org/abs/2510.09729) a rozširuje ho o viac dôkazových systémov.
